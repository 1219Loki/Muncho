# # Muncho – Recipe Finder

A responsive recipe finder web application that helps users discover meals based on the ingredients they have. The application uses **TheMealDB API** to fetch recipes and display detailed cooking information.

## ✨ Features

* 🔍 Search recipes by ingredients
* 🥘 Multiple-ingredient search
* ❤️ Save and manage favorite recipes
* 🕘 Recent search history
* 🌙 Dark / Light mode
* 🎲 Random recipe / Surprise Me
* 📅 Recipe of the Day
* 🗂️ Browse recipes by categories
* 📖 Detailed recipe information
* 📋 Copy recipe details
* 📤 Share recipes
* 📱 Responsive design
* ⚡ Loading and error states

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6 Modules)
* TheMealDB API
* LocalStorage
* Font Awesome
* Google Fonts

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/1219Loki/Muncho.git
cd Muncho
```

2. Open the project in VS Code.

3. Run `index.html` using **Live Server**.

4. Start searching for recipes using ingredients.

## 🌐 API

Recipe data is provided by **TheMealDB API**.

The application uses the API to search ingredients, retrieve recipe details, browse categories, and fetch random recipes.
